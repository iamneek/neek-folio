Skill Sewa is a Java-based web application that helps people teach and learn skills in a simple marketplace-style environment.

The platform supports:

- posting a skill as a teacher
- browsing available skills
- viewing skill details
- making bookings
- managing bookings and skill requests
- maintaining user profiles and dashboards

The project uses JSP pages, Java backend logic, and CSS-driven UI styling.

## How It Works

Skill Sewa is built around short, practical exchanges:

1. **Post a Skill**  
   Teachers share what they can teach and set a price per ten minutes.

2. **Get Booked**  
   Learners send booking requests. Teachers can accept or decline them.

3. **Connect & Teach**  
   After payment, the learner gets the teacher’s contact information to continue the session.

This makes the platform simple, focused, and accessible.
